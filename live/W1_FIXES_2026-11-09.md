## Morning series: ready-to-run commands (9 Nov, 08:00–13:00 CST)

Everything in `LIVE_LOOP.md` §6; this is the order. In a bash subshell, from the repo root:

1. Environment: the `export` block of §1 (RPC URLs, keys from the secret store, addresses), then the `export LOOPS_FILE=…`, `export AGENT_LOG=…` and helper block of §6 "Environment" (`snap`, `topup`).
2. Phase 0: `TZ=UTC date; snap | tee live/series_2026-11-09_phase0.txt`, then record `B0`/`U0` block numbers. Gas ≤ 120 → full plan; 120–180 → trimmed; > 180 → stop.
3. Phase 1:
   ```bash
   forge script script/Loop.s.sol --sig "fundReserves(uint256,uint256)" 3000000000000000000 0 --broadcast
   forge script script/Loop.s.sol --sig "fundVault(uint256,uint256)" 0 15000000 --broadcast
   forge script script/Loop.s.sol --sig "fundVault(uint256,uint256)" 1 6000000 --broadcast
   python3 script/loop_logger.py cron-check --wait-min 20      # no tick in 20 min: stop, ask reactivedevs
   forge script script/Loop.s.sol --sig "setCap(uint256)" 20000000 --broadcast
   sleep 30; snap                                              # cap 20000000, pool 20000000
   ```
4. Phase 2 (one line at a time):
   ```bash
   topup 1 1000000      # T1
   topup 0 1000000      # T2
   forge script script/Loop.s.sol --sig "pay(uint256,uint256)" 0 1000000 --broadcast   # R2: paid, record the hash
   topup 1 3000000      # T3
   topup 0 1000000      # T4
   topup 1 5000000      # T5
   topup 0 2000000      # T6

   topup 0 2000000; topup 0 2000000; topup 0 2000000   # T8-T10

   ```
5. Phase 3, not before T7 + 41 min: define `donor()` from §6, then `donor 2000000 && sleep 60 && donor 1000000 && sleep 60 && donor 1000000` (trimmed: two). Exit 2 or 3: stop and `snap`. Then `snap`; reserves < 1.5 and no top-up used yet → deposit 1.5.
